# Playbooks

Step-by-step procedures for recurring tasks. Follow them instead of improvising; if a step is
wrong or missing, fix the playbook in the same change.

| Playbook | When |
|---|---|
| [add-component.md](add-component.md) | Adding a component to the screen DSL |
| [upgrade-remote-compose.md](upgrade-remote-compose.md) | Bumping `androidx.compose.remote` |
| [upgrade-dependencies.md](upgrade-dependencies.md) | Bumping Compose, Kotlin, Ktor, AGP, … |
| [verify-on-emulator.md](verify-on-emulator.md) | Checking a change in the real app |
